# Mystic Brown

A Browntown-coloured edition of **Mystic**, published with Drunken Monk's permission.

Mystic's pixel-art structure throughout, with the UI chrome remapped onto the OSRS
Wiki's Browntown palette. The spell, prayer, skill, combat and icon art is Drunken
Monk's work and is untouched — only neutral chrome greys are recoloured.

## Palette

Chrome tones are snapped onto the wiki's published Browntown colours, taken from
`MediaWiki:Common.less/variables.less`, and interpolated between:

| variable | hex |
|---|---|
| `@ebony-brown` | `#1b1612` |
| `@mocha-brown` | `#28221d` |
| `@cacao-brown` | `#312a25` |
| `@sable-brown` | `#3e362f` |
| `@taupe-brown` | `#736559` |
| `@kharid-sand` | `#b79d7e` |

Red UI states — chat notifications, the selected chat tab, bank PIN,
Click-Here-To-Play — are preserved rather than browned, and blend continuously into
the brown so Mystic's shaded buttons keep their gradient instead of banding.
