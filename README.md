## Description

A theme inspired by the ghastly slime of Port Phasmatys and the lume found on watch faces.

I wanted to make something that felt dark and eerie, but wasn’t afraid to have a bit of colour and character. I wanted to avoid that monotonous, single-tone trap that a lot of dark themes fall into, so Ectodark is my take on something a little different.

While using Resizable Classic, it's best to use the [Compact Orbs](https://runelite.net/plugin-hub/show/compact-orbs) plugin to achieve the same look as the screenshot below.

This is my first theme published on the Hub, and I’ve had a lot of fun putting it together. If you have **any** feedback or find any UI errors, please contact me [here](#feedback). This pack wouldn't be possible without some help from the other creators listed in the [credits](#credits).

I hope you enjoy the theme :ghost:
